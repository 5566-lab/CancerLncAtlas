按精确通路组织的患者多维 Y
=============================

研究单位为“癌种 × lncRNA × 精确通路”。患者的分子测量是监督目标，
lncRNA 与通路的关系是后续建模结果。通路身份、成员、测量定义和缺失
位置均在接触 lncRNA 表达及关联结果之前固定。

一个通路身份下的多个测量维度
--------------------------

以 c 表示癌种，i 表示患者，k 表示精确通路，a 表示一个有来源和测量
定义的观测项。通路 Y 定义为带掩码的测量集合::

    Y[c,i,k] = { (a, value[c,i,a], observed[c,i,a], role[k,a]) : a in A[k] }

A[k] 包括两类观测项：与该通路等价身份对应的来源读数，以及通过明确
分子身份连接到其原始成员的测量。蛋白、磷酸化位点、蛋白编码 RNA、
CNV、启动子甲基化和调控程序分别保留其测量定义。同一患者没有某项
测量时，该项为缺失；已测零值和常量均保留。

477 条 KEGG 主干对应 477 个通路身份。一个身份下可以有多个观测项，
不会因为平台或评分算法增加了一个，就新建一条生物学通路。State
采用相同的观测组织方法，保持独立的生物学身份。

TCPA 抗体信号与 CPTAC 质谱值保留各自的观测项标识和单位，不相互
补值、不拼成一个共同活性分数。同名或相似通路不自动等价；只有正式
等价映射的来源读数可作为同一身份读数。蛋白重叠、层级关系与成员
归属保留为不同结构关系。其他库的完整蛋白列表继续用于机制结构。

成员测量的身份
--------------

一个抗体识别多个蛋白时保留一个抗体观测项。若全部被识别蛋白均属于
该通路，可作为该通路的蛋白组测量；若只有一部分属于，则记录为有
归属歧义的背景证据，不能当作某一蛋白的特异测量。CPTAC 的蛋白
异构体、残基、位点和序列标识保留，不能合并成一个基因磷酸化值。

同一观测项可以关联多个通路，但底层患者数值只保存一份。通路归属
不会使同一观测自动成为多份独立证据，也不自动增加独立损失项。

条件与观测是两个维度
--------------------

适用条件 Acond[c,i,k] 取已证实存在、已证实不存在或未知。Reference
机制不要求额外事件条件。特定变异、感染或暴露机制要求对应的事件
证据，普通成员表达、基因级突变标记或未经判定的 CNV 值不能代替。

成员观测不因条件未知而被改写或删除。但对条件性机制的专属监督，
只使用条件已证实存在的患者；未知和已证实不存在分别记录。若没有
匹配条件的患者，该机制保留定义和成员测量，不输出其专属关联结论。

TF／激酶与 PROGENy
-----------------

三者归入 Pathway。TF／激酶读数通过分子身份描述成员状态；PROGENy
保留其信号通路读数定义。分类不自动设置辅助任务。是否启用辅助
监督，以及同一通路内各观测的权重，由模型的显式任务配置规定，
不能根据数据库记录数或重复成员数决定。Pathway 总权重为 1.0，
State 为 0.5。

M0 对照
-------

每个癌种中，M0 以患者为行，预测固定的唯一观测项。同一观测跨通路
复用时只拟合一次，再通过固定归属表解释其通路关系。lncRNA、mRNA 和
两者联合三组使用相同患者、Y、观测掩码和协变量。临床与独立纯度
协变量不受 Lasso 惩罚。需要标准化的参数只由训练患者确定。

RNA 自身构成的读数在 mRNA／联合组中属于分数重建。对蛋白、磷酸化
等独立测量目标，排除目标所在组学及其直接派生输入。比较图模型时
保持监督观测和输入组学一致，改变的是模型结构。每条 lncRNA 的
系数、稳定性与条件预测增量在训练后解释，均不反向生成 Y。

数据接口
--------

cla_engine.measured_y_registry.load_target 根据精确通路 ID 与队列返回原始
患者观测、实测掩码、单独的条件适用性和来源定义。返回值不进行均值汇总、
相关分析、尺度融合或预测拟合。OBSERVATIONS 定义唯一测量，
PATHWAY_OBSERVATIONS 保存多对多归属，MATRICES 固定数值文件及校验值。

来源分类从 SOURCE_TASK_ROLES 读取，和共享生物学身份的显示角色分开。
RPPA 原始评分以内部通路 ID 命名时，通过已验证的抗体组评分定义及
正式身份重定向解析，不能用通路名猜测来源。

ESTIMATE 推算纯度与 PanImmune TLS12 公开读数保留为外部参照，原始
RNA 计算背景单独追踪；默认读取的监督观测只包含测量依赖已经核实的
项目。缺少这些项目的计算背景不改变对应生物学身份或其他已核实观测。

通路成员状态证据与来源蛋白组成
================================

研究单位是“癌种 × lncRNA × 精确通路”。KEGG 癌症机制提供主干身份。
激酶读数通过明确的 HGNC/UniProt 分子身份，连接到主干机制中的成员。
读数对应激酶复合物时，已知组成必须全部匹配；仅匹配一个亚基不代表整个复合物。

保留的关系
------------

* 来源通路 → 原始蛋白成员：保留完整来源列表、原始标识和统一后的 UniProt 标识。
* 来源通路 → 主干机制：分别记录等价身份、组成相似、父子范围和成员机制关系。
* 激酶读数 → 激酶分子 → 主干成员：作为成员状态证据进入关系 Y。
* 磷酸化读数 → 原始位点/底物：保留位点、来源方法及可用的方向信息。

原始蛋白列表不裁剪为与 KEGG 的交集。KEGG 原始成员、其他库的扩展成员和
跨库对齐分别存储，因此后续建图可以追溯每条成员边的来源。
来源归档包含完整候选清单，实际分析范围由 TARGET_POLICY.tsv 指定。

关系 Y
--------

每项读数保留原始患者值以及各 lncRNA 的调整后相关系数、p、q、有效样本量和
可估计标记。跨平台汇合的是关系证据，原始患者读数保留各自的测量单位。

连续关系强度为 sqrt(sum(w_j * rho_j**2) / sum(w_j))。同一队列、相同调整策略下
排名完全相同的重复读数共享权重 1，其余各读数权重为 1。缺失项不进入分母。
它表示与通路读数及成员状态的关系强度，方向由各原始读数的相关系数分别表达。

除综合强度外，输出分别保留同身份通路读数、成员读数，以及 RNA、蛋白、磷酸化
和甲基化等测量层的强度与读数数量。READOUT_INDEX.tsv 保留原始数组列号和来源，
因此单项读数仍可独立取出作为预测对象。

激酶活性程序读数是成员状态的估计，不等于直接测得该激酶丰度，也不等于整条
通路被激活。单纯蛋白重叠只产生结构关联，不自动成为同身份的监督读数。
条件性机制需要相应突变、病原体或暴露证据；缺少条件证据的关系保留缺失。

代码入口
----------

``relation_evidence_bindings.compile_bindings`` 只读结构和来源定义，建立读数绑定。
``multimodal_relation_y.materialize_context`` 从已冻结的分折关系数组重算 Y。
``functional_fusion.load_fused_functional_context`` 同时校验综合 Y 和分层证据。
``pathway_graph_sources.materialize_graph_sources`` 保存完整来源组成与绑定表。

显示分类不创建额外监督头；Pathway 权重 1.0、State 权重 0.5 来自显式任务策略。

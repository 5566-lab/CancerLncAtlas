通路成员状态与来源蛋白组成
==========================

研究单位是“癌种 × lncRNA × 精确通路”。先固定通路及其测量定义，
之后才分析 lncRNA 与通路的关系。

结构映射
--------

* 来源通路 → 原始蛋白成员：保留完整来源列表、原始标识和 UniProt 标识。
* 来源通路 → KEGG 主干：分别记录等价身份、组成相似、父子范围及成员机制关系。
* 激酶读数 → 激酶分子 → 主干成员：保留来源评分，作为成员状态测量。
* 磷酸化读数 → 原始位点／底物：保留位点、评分方法及方向信息。

激酶复合物需要匹配其全部已知组成；一个亚基不能代表整个复合物。
其他库的蛋白列表不裁剪为与 KEGG 的交集。原始成员、来源扩展成员和
跨库对齐分别存储，后续建图可以追溯各条成员边。

患者测量
--------

每项读数保留患者数值、测量层、平台、评分方法、单位和实测掩码。
掩码由该患者该项读数是否有有限值确定。常量和零仍是实测值，
缺失不填零。不使用 lncRNA 表达、相关系数、p/q 或关联可估计性。

同身份通路读数、成员状态读数和组成相似关系分别记录。激酶底物程序、
激酶蛋白丰度与整条通路激活具有不同测量含义。跨平台保留原始尺度。
143 个条件性机制保留明确的突变、病原体或暴露条件；成员实测掩码
不等于这些条件已满足。

代码入口
--------

relation_evidence_bindings.compile_bindings 根据结构和来源定义建立绑定。
measured_readouts.materialize_measured_readouts 输出患者读数、实测掩码及覆盖表。
pathway_graph_sources.materialize_graph_sources 保存完整来源组成与绑定表。

TF／激酶／PROGENy 归入 Pathway。独立辅助损失需显式定义训练任务，
不能由分类自动生成。Pathway=1.0，State=0.5。
